# Main against the 2026-09-27 baseline, whole suite (2026-11-18)

**Verdict: every row D82 named is now faster than the 2026-09-27 baseline it regressed from, so D82
is closed. Four uncached rows and `CompileLargePattern` are slower (1.08-1.20x) and allocate 9-13%
more: compile cost has grown since the baseline. That is a new row, D163.** Across the 76 rows both
trees have, the geometric mean of the main/baseline time ratio is 0.32 and the median 0.64.

## What was measured, and how

- **Trees:** the 2026-09-27 baseline commit `2373e273` (worktree `d82base`) and main at `b41fd1ca`
  (worktree `bdn-d82main`), each built in Release before timing. Main has 15 rows the baseline lacks;
  only the 76 common rows are compared.
- **Machine:** `windows-x64-13th-gen-intel-core-i7-13850hx`, Windows 11 23H2, mains power, CPU capped
  at 4,000 MHz (`PROCFREQMAX`), AC standby off for the run. The three other Claude sessions agreed to
  run nothing heavy; Google Drive was uploading about 50 MB.
- **Runs:** BenchmarkDotNet, whole suite, `--job medium`, `--affinity 65528` (performance cores), A-B-B-A:
  baseline 22:03-22:53, main 22:54-23:58, main again 23:59-01:02, baseline again 01:03-01:54.
  Runner `.scratch/d82/bdn-d82.ps1`, analysis `.scratch/d82/d82-abba.py`, results `.scratch/d82/bdn/`.
- **Temperature:** the package read 98-100 C near idle before the run, so the runner's wait for 86 C
  was overridden; pass 1 started without a reading. Passes 2-4 started at 78, 73 and 74 C.
- **Rule:** as the 2026-11-05 note: a row's ratio is the mean of the two main medians over the mean
  of the two baseline medians; its noise is the larger same-code ratio; a row has moved only when the
  change is more than twice its noise and more than 3%.
- **A-A controls:** baseline second pass over first, geometric mean 0.941 (range 0.805-1.131); main
  second over first, 0.996 (0.944-1.146). The baseline's first pass read about 6% slow across the
  board, the one-sided drift of a hot start. Against the second baseline pass alone the geometric
  mean is 0.330 and the median 0.678; no conclusion below changes.
