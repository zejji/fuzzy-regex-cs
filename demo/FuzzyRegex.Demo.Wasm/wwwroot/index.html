FuzzyRegex

A C# port of Python's regex module, compiled to WebAssembly and matching in your browser. The engine runs in a Web Worker, so a pattern that runs away takes the worker with it and not the page. This is v1: three inputs and the answers, nothing more.

FuzzyRegexOptions member names, separated by commas or spaces. Names only, so a typo is an error rather than a different set of flags. Version1 is the default.
